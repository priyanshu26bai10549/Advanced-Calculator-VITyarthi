# Project Statement — Advanced Calculator

## Problem Statement
Many basic calculator applications support only arithmetic operations and do not provide a structured way to perform scientific calculations, equation solving, statistics, matrix operations, and calculation-history management in one modular system.

## Scope
The Advanced Calculator provides arithmetic, scientific, mathematical, statistical and matrix operations through a Python application. It also records calculation history and provides validation and error handling.

## Target Users
- Students
- Learners studying mathematics and programming
- Users needing common scientific calculations
- Demonstration/evaluation users for the VITyarthi project

## High-Level Features
1. Basic arithmetic expression evaluation
2. Scientific functions
3. Factorial and percentage calculations
4. Linear/quadratic equation solving
5. Descriptive statistics
6. Matrix addition and multiplication
7. Calculation history
8. Logging and error handling
9. Automated tests
